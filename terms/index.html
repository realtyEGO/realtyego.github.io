1. Общие положения

Настоящие условия регулируют использование приложения «realtyego posting» (далее — «Приложение»). Приложение является внутренним инструментом RealtyEGO (бренд частного риелтора — индивидуального предпринимателя Емельянова Дмитрия Николаевича) и предназначено для публикации собственного контента владельца аккаунтов RealtyEGO.

2. Назначение Приложения

Приложение используется исключительно владельцем аккаунтов RealtyEGO для планирования и публикации собственных материалов (постов, изображений, коротких видео) в собственные аккаунты RealtyEGO: страницу Facebook*, Instagram*, Threads*, X (через сервис Buffer) и YouTube. Приложение не предоставляется третьим лицам и не предназначено для публичного использования.

3. Данные пользователей

Приложение не собирает и не обрабатывает данные других пользователей. Порядок обращения с данными описан в Политике конфиденциальности.

4. Сторонние платформы

При публикации через Приложение также действуют правила и условия соответствующих платформ (Meta* — Facebook* и Instagram*, Threads*, X, Buffer, YouTube — включая Условия использования YouTube). RealtyEGO не отвечает за работу этих платформ.

5. Ограничение ответственности

Приложение предоставляется «как есть». RealtyEGO не гарантирует бесперебойную работу Приложения и сторонних сервисов, с которыми оно взаимодействует.

6. Удаление данных

Чтобы запросить удаление данных, связанных с Приложением, напишите на realtyego@yandex.ru. Подробнее — в Политике конфиденциальности и на странице Удаление данных.
